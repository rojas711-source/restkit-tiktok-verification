How TikTok is used

Login Kit lets the store owner authorize RestKit. Content Posting API is used for video.upload, creating TikTok drafts for manual review and publishing.

Data boundary

RestKit does not send Shopify customer order data to TikTok. The uploader only uses selected video files, captions, authorization responses, and related upload status.
